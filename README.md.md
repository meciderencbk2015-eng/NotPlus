# NotPlus

NotPlus, sol menü, not ayrıntıları, sabitleme, arka plan değiştirici ve kalıcı depolama özellikleri sunan bir Java Swing not uygulamasıdır.

## Özellikler
- Sol tarafta not listesi
- Notlara arama ve sabitleme
- Başlık, kategori ve içerik düzenleme
- Kaydetme sonrası otomatik saklama
- Farklı arka plan temaları
- Ses seçenekleri
- Bilgisayar kapanıp açıldığında notların korunması

## Site yayınlama

Bu klasör içindeki `site` dizini statik web sayfası olarak kullanılabilir.
GitHub Pages veya benzeri bir statik sunucuya yüklenerek yayınlanabilir.

### GitHub Pages için
1. GitHub üzerinde yeni bir depo oluştur.
2. Bu proje dosyalarını repo içine yükle.
3. GitHub Pages bölümünden `main` dalını veya `site` klasörünü yayınla.
4. Açılan URL üzerinden siteyi görüntüle.
