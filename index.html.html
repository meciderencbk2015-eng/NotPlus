Bu sayfa GitHub Pages veya herhangi bir statik hosting servisinde yayınlanmaya hazırdır. Sadece proje klasöründeki site klasörünü sunucuya yüklemeniz yeterlidir.

  1. GitHub üzerinde bir depo oluştur.

  3. GitHub Pages üzerinden main veya site dalını yayınla.
